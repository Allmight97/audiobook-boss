## Architecture State

### Dual Engine System
- **Shell Engine**: `ShellFFmpegProcessor` via `ffmpeg::command` module
- **Native Engine**: `FfmpegNextProcessor` via `ffmpeg-next` crate
- **Selection Logic**: Feature flag controlled in `processor/selection.rs`

### Conditional Compilation Blocks
- `#[cfg(not(feature = "safe-ffmpeg"))]` - Shell FFmpeg code
- `#[cfg(feature = "safe-ffmpeg")]` - FFmpeg-Next code  
- `#[cfg(feature = "legacy-adapters")]` - Command interface code

### External Dependencies
- **FFmpeg Binaries**: Bundled in `src-tauri/binaries/`
- **Tauri Config**: External binary configuration for FFmpeg
- **Shell Commands**: `std::process::Command` usage throughout

## Known Technical Debt
