# Frontend Directives

## Routing

- Owner rules and engine pointers: `src/app/AGENTS.md`. View traps:
  `src/ui/AGENTS.md`.
- IPC adaptation, `tauriClient`, and generated bindings:
  `src/lib/tauri/AGENTS.md`.
- Provider secrets and raw provider payloads stay backend-only.

## Shape

- `src/styles.css` owns app-shell layout.
- Audiobook Boss is desktop-only.
- Solid 2 is the baseline; for version-sensitive Solid API behavior use the
  `abb-library-research` skill.
- UI behavior also needs visual review where tests cannot prove UX.
